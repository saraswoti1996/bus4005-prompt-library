BUS4005 Assessment 1 — AI Prompt Library

This repository documents the iterative development of a 10-prompt AI library for HR workflow automation, developed for a mid-sized retail organization context, submitted for BUS4005 Assessment 1: Oral Presentation with Report.

Contents
/prompt-02-resume-screening — iteration history (v1 → v2) for the resume screening prompt, with changelog
/prompt-05-offer-letter — iteration history (v1 → v2) for the offer letter personalization prompt, with changelog
/prompt-07-engagement-survey — iteration history (v1 → v2) for the employee engagement survey analysis prompt, with changelog
/full-prompt-library — final versions of all 10 prompts in the library

About
Each iterated prompt shows a version 1 (initial draft) and version 2 (refined after testing), along with a changelog explaining what was changed and why. Refinements were driven by issues observed during testing — such as the model inferring protected attributes, altering legal wording, or producing re-identifiable content — and addressed through explicit constraint-setting in the prompt text.
